# Truestorey — material evidence

The site's signature is its actual Singapore atlas. Illustrations add material and light to the editorial pages; they do not substitute for property evidence.

Warm paper #F6F5F2, ink #111414, interface teal #164F52, stone #7B837F, chalk #B6BAB6. Archivo headings, Source Sans 3 prose, IBM Plex Mono data and provenance. Existing light and dark tokens remain authoritative.

Homepage composition: opening statement + immediate search / framed real atlas; a sourced evidence strip; three reader situations; an illustrated triptych; lead story / market and notes; working tools; primary sources; author. The aesthetic risk is the restraint of an architectural material study next to an unusually large, plainspoken headline. The data does the Singapore-specific work.

## Asset discipline

Neutral overcast light from camera left, a softer fill, an oblique camera, frame-filling mineral surfaces. No landmark, building model, parcel boundary, type, currency, faces, or brand marks. The image is a conceptual illustration and says so in its alt text and article caption. Real-place subjects continue to use their existing photographs and credits.

## Reproduce

Installed renderer: Blender 5.2.1 LTS. Scene geometry and materials are generated by `render.py` from `palette.json`. `scenes/` stores the editable `.blend` files. Rendering uses Cycles CPU, fixed camera, seed and samples, with adaptive sampling disabled. Expect pixel stability on the same Blender version, CPU platform and denoiser; byte identity across render versions or hardware is not promised.

```sh
blender -b -P design/assets/render.py -- --subject all
node design/assets/encode.mjs
```

Use `--variant b` for the second camera, `--preview` for 40% dimensions, or `--subject lease` / `--subject land` individually. The GPT master is retained in `masters/`; its creation prompt is in `sun-prompt.txt`. It is a finished image, not an input mesh.

Encoding uses the sharp installation already provided by Next, adds no application dependency, produces 1600 × 900 AVIF and WebP, strips metadata, and fails above 120,000 bytes. Only these derivatives ship in `public/editorial/`. Blender master scenes and reference material are never imported by the web application.

## Extend

Create and inspect an asset, run the encoder, then add its metadata to `lib/editorial-assets.js`. The subject classifier is shared with the existing photo picker. The read layer selects local assets for approved subjects without rewriting stored articles or removing the original image references from the database. Everything else keeps its existing image treatment.
